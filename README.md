# MG EMPIRE — Elon Edition
A mobile-first Persian clicker-game prototype with an Elon Musk-inspired visual background across all tabs.

## Run
Open `index.html` in a browser, or host the files together on GitHub Pages. Keep `elon-mg-background.png` beside `index.html`.

## Notes
- Progress is saved in this browser using localStorage.
- Telegram WebApp integration is included for opening inside a Telegram Mini App.
- This is a front-end prototype only: no server, real leaderboard, shared friend rewards, blockchain/token, or real-money functionality.
